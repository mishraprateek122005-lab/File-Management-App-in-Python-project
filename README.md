# Python File Management App

## About the Project
The File Management App is a Python project developed to practice file handling and basic programming concepts. It allows users to manage files through simple operations.

## Features
- Create new files
- View available files
- Read file content
- Update existing file content
- Delete files
- Exit the program

## Technologies Used
- Python
- File Handling
- Basic Python Programming

## How to Run the Project
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or CMD.
4. Run the Python file using:

```bash
python filename.py
```

Replace `filename.py` with the actual name of your Python file.
